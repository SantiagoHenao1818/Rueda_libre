BITACORA DE DESARROLLO — RUEDA LIBRE
====================================

Estado del sitio
----------------
El proyecto ya cuenta con index.html, paginas HTML, hojas de estilo y recursos
en img/ (incluidos img/Logo.svg e imágenes de bicicletas). Se conserva la
ubicación actual de las páginas para no romper sus enlaces relativos. Se creó
paginas/ como parte de la estructura solicitada; por ahora las páginas
existentes siguen en la raíz.

1. Petición del documento en Live Server
----------------------------------------
La URL de referencia para Live Server con su configuración predeterminada es:
http://127.0.0.1:5500/index.html

Protocolo: HTTP
Host: 127.0.0.1 (localhost)
Puerto: 5500
Ruta: /index.html
Método: GET
Estado esperado: 200 OK (el servidor encontró y entregó index.html)

IMPORTANTE: esta URL y el estado son los valores habituales de Live Server,
pero quedan pendientes de confirmar en DevTools > Network. Al preparar esta
bitácora no había un servidor respondiendo en 127.0.0.1:5500; si Live Server
muestra otra URL o puerto, reemplazar aquí los datos por los de la petición
real después de recargar index.html y seleccionar la solicitud de tipo
"document".

2. Ruta inexistente
-------------------
Prueba sugerida: http://127.0.0.1:5500/promociones.html
Estado esperado: 404 Not Found.
Significado: el servidor está disponible, pero no encontró el archivo o la
ruta solicitada. Confirmar el código en la respuesta de Network de Live Server.

3. Tecnologías del sitio
------------------------
HTML: estructura y contenido. Por ejemplo, index.html organiza la navegación,
la portada, los servicios y los pasos para alquilar; Reserva.html contiene el
formulario de solicitud.

CSS: presentación y adaptación a diferentes tamaños de pantalla. Por ejemplo,
style.css define la barra de navegación, los colores y las tarjetas; usa
Flexbox para la navegación y la portada, y Grid para las tarjetas de servicios.

JavaScript: comportamiento e interacción. Por ejemplo, los botones de
navegación usan onclick para llevar a tarifas.html o Reserva.html. El archivo
js.js existe, pero actualmente está vacío y no está conectado a las páginas;
no se atribuyen al JavaScript funciones que aún no se han implementado.

4. Decisiones de diseño y responsive
------------------------------------
Flexbox se eligió para alinear elementos en una dimensión: logo y enlaces de
la navegación, y texto e imagen de la portada. En pantallas de hasta 768 px la
portada pasa a una columna y la navegación apila sus elementos; flex-wrap
permite que la portada se acomode si falta espacio.

Grid se eligió para colecciones en dos dimensiones, como tarjetas de servicios,
pasos e información. Las columnas con repeat(auto-fit, minmax(...)) se ajustan
al ancho disponible. En el formulario de Reserva.html, la cuadrícula de dos
campos pasa a una columna en pantallas de hasta 768 px. La tabla de tarifas
puede desplazarse horizontalmente dentro de .table-responsive.

Estas reglas atienden el desbordamiento de la navegación, la portada, las
tarjetas, el formulario y la tabla en pantallas estrechas. Se registran como
decisiones visibles en el código actual, no como una comparación con Bootstrap.

5. Bootstrap
------------
Bootstrap todavía no está implementado. El sitio usa HTML y CSS propios; esta
bitácora queda como referencia para comparar más adelante su estructura y
comportamiento responsive con una versión hecha con Bootstrap.

6. Control de versiones
-----------------------
El repositorio ya tenía commits anteriores a esta bitácora. El commit que
registra esta entrega debe describir la incorporación de la bitácora y la
estructura solicitada; por lo tanto, no es el primer commit histórico del
repositorio.
